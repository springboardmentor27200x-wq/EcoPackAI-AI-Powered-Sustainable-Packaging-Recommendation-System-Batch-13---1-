# 🌱 AI-Based Sustainable Material Recommendation System

## 📌 Project Description
This project is a web application that helps users select the best material based on:
- Budget 💰
- Eco-friendliness 🌍
- Durability 🛠

It also provides a dashboard to visualize:
- CO₂ reduction
- Cost savings
- Material usage trends

---

## 🚀 Live Demo
🔗 Website Link: https://material-recommendation.onrender.com/
📊 Dashboard Link: https:https://material-recommendation.onrender.com/dashboard 

---

## 🚀 Features
- ✅ Material recommendation based on user input
- 📊 Interactive dashboard using Plotly
- 📉 CO₂ Reduction analysis
- 💰 Cost Savings analysis
- 📈 Material Usage Trends
- 📥 Download results as CSV
- 📄 Download results as PDF
- 🌐 Deployed on Render

---

## 🛠 Technologies Used
- Python (Flask)
- HTML, CSS, Bootstrap
- PostgreSQL Database
- Plotly (Graphs)
- Pandas (Data Processing)
- ReportLab (PDF Generation)

---

## 📂 Project Structure
- `Python Final code` → Backend (Flask App)
- `templates/index.html` → Home Page
- `templates/dashboard.html` → Dashboard Page
- `static/style.css` → Styling
- `requirements.txt` → Dependencies

---

## 🗄 Database
- Database: PostgreSQL
- Table Name: `material`
- Data imported from CSV dataset

---

## ⚙️ Environment Variables
Set these variables in Render:

DB_HOST=your_host  
DB_NAME=your_database  
DB_USER=your_username  
DB_PASSWORD=your_password

## ▶️ How to Run Locally
1. Install dependencies:

2. Run the application:
